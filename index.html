Design tokens for Zaniah

Make the theme inspectable before it reaches the interface.

Auva loads JSONC into a validated Zaniah theme, checks essential contrast pairs, and exports deterministic sheets for every token category.

Install the gemRead the guide
// tokens.jsonc
{
  "extends": "dark",
  "colors": {
    "accent": "#83b79f",
    "background": "#080c0b"
  },
  "motion": {
    "reduced": true
  }
}

Bad tokens fail where they are written.

The schema comes from Zaniah's theme members, so validation tracks the real interface contract instead of a parallel copy.

Parse

Accept comments and trailing commas while retaining source ranges.

Validate

Reject unknown categories, members, types, colors, and shadow fields with a line and token path.

Check

Measure WCAG AA and AAA contrast for the color pairs users depend on.

Inspect the whole system, not a single swatch.
